What got locked in

Orange accent scope

Option A — strict. #FF6B00 marks interactive elements only: buttons, links, focus rings. The mockups used it on section eyebrows, the "in plain English" label and the positioning pill; those have been rolled back to white and muted grey, with the monospace face carrying their distinctiveness instead.

07 §2 stays as written. No doc amendment needed.

Hero location line

Shape confirmed as remote availability only — no city or country. The exact wording is still outstanding, so nothing has been written into any component. The invented "Kuwait — remote friendly" line is gone and has not been replaced with a guess.

Blocks the Hero in Phase 3, not Phase 1.
Colour roles

Seven roles, one palette

Tokens are named by role, not by hue — action means "act on this", live means "confirmed and working". Misuse is visible at the call site. Contrast ratios are measured, and every one clears WCAG AA for normal text, including the two spots 07 §8 flagged as likely to fail.

Typography

Three faces, three jobs

Display carries confidence in headlines and never touches body copy. Body disappears so the writing can do the work. Mono appears in the same fixed handful of places sitewide — tags, dates, stat labels, eyebrows — which is what makes it read as a system rather than a third font.

Spacing rhythm

The 8px scale

Tailwind's default 4px base is left untouched, because it expresses every step of 07 §4's 8px rhythm exactly. Redefining the base would silently change what every utility class means for whoever reads this code in two years. Use the even steps; avoid the odd ones.

@for (s of spacing; track s.step) {
{{ s.px }}px p-{{ s.step }}
}
Shared components

Built once, reused everywhere

Button

Attribute selector, so the host stays a real <button> or <a> — semantics and keyboard behaviour come from the platform. One primary per section.

Anchor, same component

Tab to any of these to see the focus ring — orange is correct there, focus is an interactive affordance.

Tag

Monospace, muted, hairline border. Supporting information that must never compete with a headline. Deliberately not interactive — that is what keeps orange meaningful.

@for (tech of demoStack; track tech) { {{ tech }} }

Real stack from the Scholarship Operation Dashboard (03 §4) — demo content should not invent technologies either.

Status dot

The signature element (07 §6). Borrowed from Muhammed's own dashboards, where a status dot means something real. It has no colour or tone input, so it can only ever mean "live" — the rule enforced in code rather than left for a reviewer to catch.

Bare dot, beside text that carries the meaning

The pulse disappears under prefers-reduced-motion; the dot still reads as live. Only the movement is removed, not the meaning.

Eyebrow & card

Eyebrows are white and muted grey, not orange — the Option A rollback. Cards get depth from the surface shift, never from stacked shadows.
